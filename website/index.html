Your API requests are files.

Reqnest is a native Mac client for REST, GraphQL, gRPC, WebSocket, SSE and MCP. Each request is a small YAML file: review it in a pull request, run it in CI, keep it forever. Bring your Postman collections along, and ask your own AI model about any request. No account, no cloud, no telemetry.

Reviews that read like code reviews

Keys are always in the same order. There are no generated IDs and no sequence numbers. Bodies are literal blocks, so a changed JSON field is one changed line in the diff.

The collection is a folder. Open it in any editor, check it in, run it in CI with the CLI. If you stop using Reqnest tomorrow, you still have readable files.

  • Secrets live in .reqnest/secrets.yaml, which is git-ignored for you.
  • Order comes from file names, never from file contents.
  • Edits made outside the app are picked up when the window regains focus.

Bring your Postman collections with you

In Postman, open Settings, Data, Export Data. In Reqnest, choose Import and pick that folder. Every collection, environment and your globals come across in one go.

  • Each collection becomes a folder. Its folders keep their own auth, variables and scripts.
  • OAuth 2.0, API key, bearer and basic auth, form-data, file and GraphQL bodies, and saved example responses are carried over.
  • Your pre-request and test scripts run as they are: pm.test, pm.expect, pm.environment, pm.response.
  • Passwords and tokens are moved out of the files into variables on your Mac, so nothing secret gets committed.

Digest, AWS and NTLM auth and pm.sendRequest are not supported yet. The import lists everything it could not carry over.

Ask your own model about a request

Open the panel, type a question, and the model answers with your request open in front of it: the method, URL, headers, body and, if you allow it, the last response.

  • Works with Ollama and any OpenAI-compatible server: OpenAI, OpenRouter, LM Studio, vLLM, Groq.
  • Paste the curl command you already use and the endpoint, model and token are filled in. A token is optional.
  • Credentials are hidden and {{variables}} stay unresolved. The panel shows exactly what is sent.

Questions go straight from your Mac to the endpoint you set, and nowhere else.

Get Reqnest

macOS 11 or later. One universal build for Apple silicon and Intel.

Download Reqnest.dmg All releases

Open the DMG and drag Reqnest into Applications. Reqnest is not signed with an Apple Developer ID yet, so macOS blocks the first launch. Run xattr -dr com.apple.quarantine /Applications/Reqnest.app in Terminal once, or open System Settings, Privacy & Security and choose Open Anyway.

# build from source: needs Node 20+ and Rust
git clone https://github.com/batuhanilgarr/Reqnest.git
cd Reqnest && npm install
npm run tauri build

Questions

What does it cost?

Pricing is announced on this page and in the releases. Your collections are plain files, so you are never locked in: they stay readable without Reqnest.

What does it send to your servers?

Nothing. There is no account, no analytics and no telemetry. Requests go straight from your Mac to the API you are calling. The one other thing that can leave your Mac is a question you ask the AI assistant, and it goes only to the endpoint you configured.

How do I move over from Postman, Bruno or Insomnia?

For Postman, export your data (Settings, Data, Export Data) and import that folder in one step: collections, environments, globals, auth and your scripts come across. For Bruno, import its folder; for OpenAPI, import the spec; and any curl command can be pasted straight into the URL bar.

Where are my secrets stored?

Variables marked as secret live in .reqnest/secrets.yaml, which Reqnest adds to .gitignore. Tokens fetched by OAuth stay in memory only.

Does the AI assistant need an account or a subscription?

No. You bring the model: Ollama running on your machine or server, or any OpenAI-compatible service you already use. Reqnest adds nothing in between. A token is optional, and credentials from your requests are hidden before a question is sent.

Windows and Linux?

The app is built on Tauri, so other platforms are possible. Today it targets macOS. The CLI already runs anywhere Node 20 does.

Can scripts access my files?

In the app, scripts run in an isolated sandbox with a time limit and cannot reach your files or secrets. The CLI runs them in a Node worker, so treat CLI scripts like the rest of your CI code.
